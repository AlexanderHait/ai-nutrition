AI-Nutrition V9 — support + bot activity

1. В Supabase SQL Editor выполнить:
   supabase/migrations/003_interactions.sql

Создаются только две новые таблицы:
- bot_events — значимые события Telegram-бота;
- support_messages — личный диалог клиент ↔ администратор через сайт.

2. Затем залить проект целиком и сделать Vercel Redeploy.

3. Что изменится на сайте:
Клиент:
- новая вкладка «Поддержка»;
- переписка с администратором с автообновлением примерно раз в 5 секунд.

Администратор:
- «Диалоги» теперь показывает только сообщения, адресованные человеку;
- переписка клиента с AI там больше не шумит;
- в карточке клиента вместо AI-чата показывается «Активность питания»:
  распознано фото, сохранён приём, правки и т.п.

4. bot_events начинает наполняться после установки n8n workflow V9.
