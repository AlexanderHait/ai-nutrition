AI-Nutrition V10 UX

Что изменено:

1. Непрочитанные сообщения
- В админском меню рядом с «Диалоги» отображается badge с количеством непрочитанных сообщений клиентов.
- На мобильной нижней навигации badge виден прямо на иконке.

2. Питание
- История стала компактной.
- День = одна компактная карточка.
- Внутри дня строки сгруппированы в реальные приёмы пищи по времени (до 12 минут между позициями).
- Фото с 6 блюдами теперь считается одним приёмом, а не шестью.
- Состав многокомпонентного приёма раскрывается по клику.

3. Главная клиента
- «Приёмов» считает реальные приёмы пищи, а не количество строк meals.
- Например 1 одиночный приём + фото из 6 позиций = 2 приёма, 7 позиций.

4. Прогресс
- Каждый день в «Калории · 7 дней» кликабельный.
- Переход открывает /client/nutrition?day=YYYY-MM-DD и нужный день подсвечивается/поднимается наверх.

5. Админская аналитика
- «Среднее за 7 дней» теперь считается по client-day, а не по сумме всех клиентов.
- «Калории за 7 дней» показывает среднее на активного клиента по каждому дню.
- Для каждого дня видно количество активных клиентов.
- Блоки стали компактнее и легче читаются.

SQL не требуется.
Просто залить проект и сделать Vercel Redeploy.
