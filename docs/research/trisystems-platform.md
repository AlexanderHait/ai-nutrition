# Разбор платформы Trisystems и что из неё взято в TeddY

Разбор от 16.10.2026. Источники: публичные страницы trisystems.ru (главная, Premium, лаборатория, кэмпы, лекции, статьи, оферта, RSS) и код браузерного приложения app.trisystems.ru, который сайт отдаёт любому посетителю. В аккаунт не входили, запросов к их API не делали. Ключевые утверждения перепроверены отдельным проходом по исходникам: подтверждено 80, опровергнуто 2 (мелочи), не проверить 3.

## Коротко

Trisystems — онлайн-сервис подготовки к триатлону. **Это не AI-сервис**: в коде нет ни нейросети, ни чата-тренера. Ядро — детерминированный генератор плана. Человек выбирает старт и дату, вводит свои пороги. Сервер раскладывает недели до старта по этапам из каталога шаблонов и пересчитывает каждую тренировку под человека. Дальше идёт календарь «план против факта» и пересборка при изменениях.

## Как устроено

**Два сайта.** Маркетинг — Tilda (trisystems.ru): обещание, «для кого», 5 шагов, результаты спортсменов по именам, цена «от 11 900 ₽ за 3/6/12 месяцев». Все кнопки покупки ведут в приложение app.trisystems.ru. Там React, вход по коду на email (SuperTokens), оплата YooKassa (рубли) и Stripe (доллары). Бэкенд по косвенным признакам на Kotlin/Spring.

**Путь клиента в приложении.**
1. Оплата до регистрации: достаточно email. Без оплаты доступны только страница тарифов и отчёты лаборатории — отчёт служит воронкой.
2. Анкета в 3 шага: о себе → рост, вес, бассейн → пороги по трём видам спорта. Есть калькулятор порогов по недавнему максимальному усилию.
3. Недельное расписание: в какие дни какой вид спорта. Перетаскиванием, не больше 2 в день.
4. «Старт» = план: тип (железка, половинка, олимпийка, межсезонье), приоритет A/B/C, даты. Один активный старт A. Ограничения на даты: не ближе 5 дней, B и C строго относительно A.
5. Генерация на сервере, асинхронно: черновик → активен (или ошибка). Клиент опрашивает статус каждые 5 секунд.
6. Календарь день/неделя/год. Карточки: выполнено, пропущено, сегодня, запланировано. Перенос перетаскиванием. Склейка плановой тренировки с фактической из Garmin. Сводка недели «план/факт».
7. Отправка тренировки на часы (Garmin, COROS) в окне «сегодня + 3 дня».
8. После гонки — ввод результата. Следующий цикл — новый старт, в том числе межсезонье.

**Как считается план.** Каталог в базе: тип старта → макроцикл → мезоциклы → недели → шаблоны тренировок → шаги. Каждый шаг хранит не абсолютные числа, а коэффициенты к порогу человека (пульс, мощность, темп). При сборке коэффициенты умножаются на пороги — получаются личные цели. Смена порогов или веса пересобирает план на сервере. У админа есть редактор каталога и превью «собрать план из этих вводных».

**Адаптация.** Сайт обещает коррекцию после пропуска и пересоздание плана после паузы больше двух недель. В коде браузера видно только пометку «пропущено» и ручной перенос. Перераспределяет ли сервер нагрузку, из кода не установить.

**Деньги.** Один платный уровень (роль ATHLETE), основной тариф годовой, есть бесплатный пробный тариф по флагу. Отдельно Premium: 90 000 ₽ за 3 месяца, живой тренер, врач, лабораторные тесты раз в 3 месяца. Продаётся через заявку на консультацию, а не через корзину. Вокруг — лаборатории в нескольких городах (в том числе франшиза), кэмпы, лекции, статьи, календарь стартов.

**Админка.** Выдача и продление подписок; воронка «пытались оплатить, но не оплатили», «зарегистрировались без оплаты», «не продлили»; ручные напоминания «нет активности» и «подписка заканчивается»; Garmin-инструменты; лаборатории; каталог плана с превью.

**Что продаёт.** Список «эти тренировки вы делать будете / не будете», опора на лабораторные данные, имена и время спортсменов, честное «будет тяжело». Слабые места текста: цифры на разных страницах не сходятся.

## Что не установлено

Алгоритм генерации целиком (сколько недель на этап, как масштабируется объём), содержимое каталога, формулы порогов, серверная адаптация после пропусков, цены по срокам (приходят с сервера), тексты интерфейса (грузятся отдельными файлами). Календарь стартов tricalendar.trisystems.ru не открылся из нашей сети.

## Перенос на TeddY: «Программа к цели по дате»

| Trisystems | TeddY |
| --- | --- |
| Старт и дата | Цель (снижение, удержание, набор), целевой вес и дата |
| Пороги человека | Анкета: пол, возраст, рост, активность, свежий вес → расход Mifflin–St Jeor (та же формула, что в анкете) |
| Каталог: этапы и шаблоны с коэффициентами | Каталог правил в `lib/goal-program.ts`: мягкий вход, основной этап, неделя на поддержании каждые 8 недель, закрепление 2 недели после даты. Доля дефицита по этапам вместо коэффициентов к порогу |
| Сборка плана на сервере | Детерминированный расчёт в коде, без AI; в базе только выбор человека и снимок анкеты (`nutrition_programs`) |
| Ограничения на даты стартов | Пределы безопасности: не быстрее 1% веса в неделю (набор 0,5%), дефицит до 25% расхода (профицит до 15%), не ниже минимума калорий, не младше 18 лет, цель не ниже ИМТ 18,5. Нереалистичная дата → отказ и ближайшая реальная дата |
| Календарь «план/факт», статусы тренировок | Неделя за неделей: средние калории против ориентира («в плане / рядом / мимо / мало записей / нет записей») и вес против плановой линии |
| Пересоздание после паузы больше 2 недель | Подсказка «пересобери от текущего веса» после двух недель без записей, при отставании веса при питании в плане и при двух неделях далеко от плана. Сама программа ничего не меняет |
| Смена порогов пересобирает план | Пересборка от сегодняшнего дня и текущего веса; прошлая программа остаётся в истории |
| Цели тренировок в часах | Ориентиры недели пишутся в профиль только по кнопке человека: их видят бот, дневник и Coach |

**Не перенесено намеренно.** Отправка на устройства, лаборатории, приоритеты A/B/C (у питания одна главная цель), асинхронная генерация (расчёт мгновенный), оплата до регистрации.

**Кандидаты на следующие шаги.** Воронка неоплат в админке (у TeddY есть подписки, но нет такого отчёта). Ручное напоминание «нет активности». Блок программы в контексте бота и недельного разбора Premium. Уточнение расхода по фактическим данным — аналог калькулятора порогов: средние калории против изменения веса за 2–3 недели.
