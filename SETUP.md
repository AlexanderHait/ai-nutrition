# Перенос TeddY в Claude Code

Инструкция с нуля. Все команды вставляются в Терминал целиком, по одной, каждая заканчивается нажатием Enter.

Терминал открывается так: Cmd + Пробел → напечатать `Терминал` → Enter.

---

## Шаг 1. Установить Claude Code

```
curl -fsSL https://claude.ai/install.sh | bash
```

Закрыть Терминал и открыть заново. Проверить:

```
claude --version
```

Должен появиться номер версии. Если пишет `command not found` — перезапустить Терминал ещё раз.

---

## Шаг 2. Создать папку проекта и скачать код

```
mkdir -p ~/TeddY && cd ~/TeddY
git clone https://github.com/AlexanderHait/ai-nutrition.git .
```

Если попросит логин — вводи имя пользователя GitHub, а вместо пароля Personal Access Token (github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate).

**Важно:** в Claude Code MCP-коннектор для GitHub не нужен вообще. Claude Code работает с кодом напрямую через `git` — читает файлы, правит, коммитит и пушит. Это надёжнее MCP.

---

## Шаг 3. Файлы контекста

Ничего копировать и переименовывать не нужно — `CLAUDE.md` и `.mcp.json` уже лежат в репозитории и приходят вместе с кодом при клонировании.

Проверить, что оба файла на месте:

```
cd ~/TeddY && ls -a CLAUDE.md .mcp.json
```

Должны показаться оба имени. `CLAUDE.md` Claude Code читает автоматически при каждом запуске в этой папке — отдельно ничего включать не нужно.

---

## Шаг 4. Запустить и подключить сервисы

```
cd ~/TeddY && claude
```

При первом запуске Claude Code спросит, доверяешь ли ты `.mcp.json` из этой папки — ответить **да**.

Дальше внутри Claude Code:

```
/mcp
```

Появится список: `supabase`, `vercel`, `n8n`. У каждого нажать Authenticate и пройти вход в браузере.

Проверить, что всё поднялось:

```
/mcp
```

Все три должны быть в статусе connected.

---

## Шаг 5. Проверка

Внутри Claude Code написать:

```
Проверь доступы: список workflow в n8n, список таблиц Supabase, последний деплой Vercel. Ничего не меняй.
```

Если всё ответило — перенос завершён.

---

## Про n8n

Адрес `https://n8n-config-production.up.railway.app/mcp-server/http` работает только если на инстансе включён instance-level MCP.

Проверить: открыть n8n → **Settings → Instance-level MCP** → включить. Там же на странице MCP Access показан точный URL — если он отличается от того, что в `.mcp.json`, подставить показанный.

Если раздела нет — значит версия n8n на Railway старее нужной, инстанс надо обновить. Тогда n8n временно останется без прямого доступа, а всё остальное будет работать.

## Полезные команды внутри Claude Code

| Команда | Что делает |
| --- | --- |
| `/mcp` | Список и статус подключений |
| `/clear` | Очистить контекст текущего разговора |
| `/resume` | Вернуться к предыдущему разговору |
| `Esc` | Прервать текущее действие |
| `/exit` | Выйти |

Начать новую сессию: `cd ~/TeddY && claude`
Продолжить прошлую: `cd ~/TeddY && claude --continue`
