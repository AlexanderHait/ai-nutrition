TeddY — интеграция фото в Диалоги v2

Заменить/добавить файлы из архива в корень GitHub-репозитория с сохранением путей.

Включено:
- кнопка-скрепка в РЕАЛЬНОЙ странице /admin/dialogs;
- выбор и preview фото;
- текст + фото или только фото;
- показ фото клиента/администратора в истории;
- открытие изображения поверх страницы;
- приватные signed URL;
- admin auth на upload endpoint;
- вызов teddy-support-reply-v20 после ответа администратора.

Важно: исходный архив не содержит node_modules, поэтому локальный Next build в sandbox выполнить невозможно. После загрузки проверить Vercel build.
